Kolam is not just decoration — it is a system.

Each pattern is built on rules: dots, symmetry, flow, and repetition. Ulsoor explores what happens when those rules become a digital tool — something you can adjust, play with, and understand as a living geometry.

01 · Canvas

Draw from a grid, not a blank page.

Start with a dot grid and a base shape. The canvas builds the pattern from there — using the same logic that governs traditional kolam: symmetry, flow, and repetition from a defined starting point.

02 · Controls

Adjust the geometry, change the pattern.

Choose your base shape, set the grid size, and watch the pattern respond. Each change reveals how the underlying rules produce different visual outcomes from the same simple structure.
